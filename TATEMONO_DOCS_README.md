## 🔑 Critical Syntax Discoveries

### Database Columns — DICT FORMAT ✅
```yaml
/* @arkzen:database:items
table: items
columns:
  id:
    type: integer
    primary: true
    autoIncrement: true
  name:
    type: string
    length: 255
    nullable: false
*/
```

**NOT an array.** Column name is key, properties are values.

---

### API Endpoints — DICT FORMAT ✅
```yaml
/* @arkzen:api:items
endpoints:
  index:
    method: GET
    route: /items
    response:
      type: collection
  store:
    method: POST
    route: /items
    validation:
      name: required|string
    response:
      type: single
*/
```

**NOT an array.** Endpoint method name (index, store, show, etc.) is key.

---

### Notifications Channels — ARRAY FORMAT ✅
```yaml
/* @arkzen:notifications:alert-all
channels: [database, mail, broadcast]
message: "Multiple channel notification"
subject: "Alert"
channel_type: private
*/
```

**Always ARRAY.** Options: database, mail, broadcast. Can combine multiple.

---

### Mail Definition — YAML + HTML ✅
```yaml
/* @arkzen:mail:welcome
subject: "Welcome"
data:
  username: string
  app: string
*/
<!-- Blade HTML goes here -->
/* @arkzen:mail:welcome:end */
```

**HTML body after YAML**, not in a field. No explicit blade_body property.

## ✅ Validation Checklist

When creating a new tatemono, verify:

- [ ] @arkzen:meta (name, version, description, auth setting)
- [ ] @arkzen:config (toast/modal/layout settings)
- [ ] @arkzen:database (if using DB — columns as DICT)
- [ ] @arkzen:api (if using API — endpoints as DICT)
- [ ] Validation rules in endpoints (use Laravel rules format)
- [ ] Response type for each endpoint (collection, single, message, paginated)
- [ ] @arkzen:mail (if sending mail — yaml + html body)
- [ ] @arkzen:notifications (if notifying — channels as ARRAY)
- [ ] @arkzen:components:shared (React setup, imports, types)
- [ ] @arkzen:page (at least one page with layout specified)
- [ ] auth_seed (if auth:true — seed test users with roles)
- [ ] middleware array (if needed — auth, role:admin, custom names)
