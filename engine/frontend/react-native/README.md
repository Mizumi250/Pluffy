# Arkzen Engine — React Native Stack (v9)

## Status: Foundation / Partial

This is the React Native stack for Arkzen v9.
Same tatemono DSL — native mobile output.

---

## Architecture

```
Same tatemono DSL → React Native screens + React Navigation
Same Laravel backend → API is identical (same endpoints)
Same auth (Sanctum) → Token stored in SecureStore instead of cookies
```

---

## How to Run the Engine

```bash
cd engine/frontend/react-native
npm install
npm run arkzen
```

The engine watches `tatemonos/` and generates:
- `src/screens/{tatName}/{screenName}.tsx` — placeholder screens
- `src/arkzen/generated/routes.ts` — React Navigation stack config

## Key Differences from Web Stacks

| | Next.js / React+Vite | React Native |
|---|---|---|
| **Routing** | File-based / React Router | React Navigation |
| **Styling** | Tailwind / CSS | StyleSheet.create({}) |
| **Elements** | div, p, button | View, Text, TouchableOpacity |
| **Auth storage** | Cookies / localStorage | SecureStore |
| **Navigation** | navigate('/path') | navigation.navigate('key') |
| **Scroll** | overflow-y: scroll | ScrollView |
| **Lists** | .map() | FlatList |
| **Backend** | Same Laravel API | Same Laravel API |
| **Build** | Next.js / Vite | Expo / Metro |

## Generated Screen Structure

For each `@arkzen:page:name` block, the engine generates a screen like:

```tsx
// src/screens/my-app/dashboard.tsx
export function DashboardScreen({ navigation, route }: Props) {
  return (
    <SafeAreaView>
      {/* Placeholder — replace with native components */}
      {/* Web JSX reference is in a comment block */}
    </SafeAreaView>
  )
}
```

The original web JSX from the tatemono is preserved as a comment block
inside the screen file, so you can see the layout/logic and rebuild it
with native components.

## Expo Setup (to actually run the app)

> This is separate from the Arkzen engine — the engine generates code,
> Expo runs it.

```bash
# Create a new Expo project and copy generated src/ into it
npx create-expo-app ArkzenApp --template blank-typescript
cd ArkzenApp

# Install navigation deps
npm install @react-navigation/native @react-navigation/native-stack
npm install react-native-screens react-native-safe-area-context

# Copy generated files
cp -r engine/frontend/react-native/src/* .

# Run
npx expo start
```
