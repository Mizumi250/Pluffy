# Backend conformance vectors

`validation-vectors.json` (177 cases, generated by `gen_vectors.py`) is the shared validation contract.
Expected results follow Laravel and the Express runtime. Every backend runs the same file:

| Backend | Command | Vector copy |
|---|---|---|
| Express | bundle `express/src/runtime/validation.ts` and feed the vectors (see checklist) | this folder |
| FastAPI | `cd fastapi && pytest tests/test_validation_conformance.py` | `fastapi/tests/` |
| Spring | `javac -d out -sourcepath src/main/java src/test/java/dev/pluff/runtime/ValidationConformance.java && java -cp out dev.pluff.runtime.ValidationConformance src/test/resources/validation-vectors.json` | `spring-boot/src/test/resources/` |
| ASP.NET | `cd conformance/aspnet-runner && dotnet run -- ../validation-vectors.json` | this folder |
| Go | `cd go && go test ./internal/backend -run TestValidationConformanceVectors` | `go/internal/backend/testdata/` |
| Rust | `cd rust && cargo test validation::` | `rust/tests/` |

After editing `gen_vectors.py`, rerun it and copy the JSON to each vector copy above.
Not covered (unsupported on every non-Laravel backend): date_format, after*, before*, digits_between.
Not covered (need I/O): unique, exists, file, image, mimes, mimetypes.
